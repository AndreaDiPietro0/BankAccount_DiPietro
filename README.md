# Bank Account (C++ / Qt)

University project for Programming, University of Florence.

A desktop application that models a bank account, written in C++ with a graphical interface built with Qt. Deposit, withdraw, balance check, transaction history.

## Features
- Deposit and withdrawal with input validation
- Balance and transaction history view
- Save different profiles

## Concepts practiced
- Classes and encapsulation in C++
- A GUI built with Qt
- Separation between account logic and interface.
